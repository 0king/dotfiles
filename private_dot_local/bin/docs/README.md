# intro
putting all my scripts here and using chezmoi for sync/backup

# rules
- use `<script-name>.README.md` to provide documentation for that script
- don't ignore out/ dir - back it up (it has data generated by scripts)

# dir structure
- **~/.local/bin/** (directly on `$PATH`):
  - Scripts flattened using `<directory>_<file>` naming pattern (e.g. `git_create-github-repo.sh`, `ubuntu_list-installed-apps.ubuntu.sh`, `vscode_vscode-projects.sh`, `bootstrap_*.sh`, etc.)
- **code/** (off `$PATH`): C / C++ and other source code files (e.g. `check-c-version.c`)
- **docs/** (off `$PATH`): Documentation, script guides, and READMEs
  - `chezmoi_check-unmanaged.sh.README.md`: Detects and alerts on unmanaged/new files in managed directories during status
  - `git_create-github-repo.readme.md`: Interactive GitHub repository creator and initial commit helper
  - `kanata_update_config.README.md`: Kanata keyboard configuration updater and systemd service reloader
  - `terminal-keymap.md`: Unified terminal keybindings and actions reference (Kitty, Alacritty, WezTerm, Ghostty)
- **out/** (off `$PATH`): Script-generated data snapshots, audit logs, and reports
