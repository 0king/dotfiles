| Action | Keybinding |
| :--- | :--- |
| Copy on select | Mouse highlight |
| Select all | `Ctrl + Shift + A` |
| Vim mode | `Ctrl + Shift + Space` / `Ctrl + Shift + X` |
| Copy | `Ctrl + Shift + C` / `Ctrl + Insert` |
| Paste | `Ctrl + Shift + V` |
| Paste selection | `Shift + Insert` |
| Line scroll up | `Ctrl + Shift + Up` / `Ctrl + Shift + K` |
| Line scroll down | `Ctrl + Shift + Down` / `Ctrl + Shift + J` |
| Page scroll up | `Shift + PageUp` / `Ctrl + Shift + PageUp` |
| Page scroll down | `Shift + PageDown` / `Ctrl + Shift + PageDown` |
| Scroll to top | `Shift + Home` / `Ctrl + Shift + Home` |
| Scroll to bottom | `Shift + End` / `Ctrl + Shift + End` |
| Search buffer | `Ctrl + Shift + F` |
| New window | `Ctrl + Shift + N` |
